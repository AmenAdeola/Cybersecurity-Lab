
# Protect Data and Communicate Incidents

## Security as a Mindset

Security should be integrated into everyday decisions rather than treated as a separate activity.
- Think before acting.
- Protect sensitive information.
- Follow established procedures.
- Report suspicious activity quickly.
- Document evidence accurately.
- Avoid sharing unnecessary confidential details.


## Event vs Incident

| Term | Meaning | Example |
|---|---|---|
| Event | Any observable occurrence in a system or network | User login, file access, application start |
| Security event | An event relevant to security monitoring | Repeated failed logins |
| Incident | An event that threatens confidentiality, integrity, or availability | Unauthorized access, malware infection, data breach |

## Data Classification

| Classification | Description |
|---|---|
| Public | Approved for public disclosure |
| Internal-only | Intended for organizational use |
| Confidential | Limited to authorized personnel |
| Restricted | Highly sensitive and strictly need-to-know |

## Asset Protection Responsibilities

- Apply least privilege.
- Use approved systems and secure communication channels.
- Protect credentials and authentication factors.
- Escalate suspected incidents.
- Preserve relevant evidence.
- Follow retention, privacy, and data-handling requirements.

## Business Continuity and Disaster Recovery

- Business continuity keeps critical operations available during disruption.
- Disaster recovery restores systems, applications, and data after an outage or incident.
- Common measures include backups, alternate systems, recovery procedures, and regular testing.


## Incident Communication

A useful incident communication should state:

1. What was observed
2. When it occurred
3. Which systems or users may be affected
4. What evidence is available
5. What actions have already been taken
6. Who has been notified
7. What decision or support is required

Do not declare an incident solely because one suspicious indicator exists. Distinguish an observation, an alert, and confirmed evidence.
