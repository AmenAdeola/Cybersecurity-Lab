# Threats to Asset Security

# Threats Actors

Threat actor | Description | Example|
-------------|-------------|--------|
External Threat Actor| Person or group outside the organization| Hacker, Hacktivist, Organized Crime
Insider Threat| Person with authorized access who misuses it | Employee, contractor
Competitor | Organization seeking advantage | Industrial Espionage
Nation-State | Governement-sponsored attacker| Cyber Warfare
Script Kiddie | Inexperienced attacker using existing tools| Automated Exploits

### Examples of Threat Actors

| Actor | Potential motivation |
|---|---|
| Cybercriminal | Financial gain |
| Insider | Malicious intent or accidental misuse |
| Competitor | Strategic advantage |
| Nation-state | Espionage or disruption |
| Script kiddie | Curiosity or reputation |

## Threat Events

- Credential theft
- Unauthorized access
- Data exfiltration
- Malware execution
- Service disruption
- Information modification or deletion
- Physical theft
- Supply-chain compromise

## Common Weaknesses

- Weak passwords
- Missing MFA
- Excessive privileges
- Unpatched systems
- Public exposure
- Poor encryption
- Inadequate logging
- Insufficient user awareness

## Analysis Pattern
```text
Asset + threat actor + vulnerability + threat event + impact + control
```
## Example
```text
Customer database
 + external attacker
 + public exposure
 + data exfiltration
 = confidentiality and regulatory impact
→ restrict access, MFA, encryption, monitoring
```
