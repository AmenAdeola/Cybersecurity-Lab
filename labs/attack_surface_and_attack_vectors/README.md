# Attack Surface and Attack Vectors

## Overview

This project analyzes potential attack vectors and attack surfaces associated with a USB baiting scenario.
A suspicious USB drive discovered in a parking lot was examined from both a defender's and attacker's perspective. The exercise focuses on identifying information that could be used in social engineering attacks, assessing the risks associated with removable media, adn recommending controls to reduce exposure to USB-based threats

## Outcome

This project demonstrates how seemingly harmless information stored on removable media can create security risks and how attackers may use both malware and social engineering techniques to compromise an organization.
