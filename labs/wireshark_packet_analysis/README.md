# Wireshark Packet Analysis

## Overview

This project demonstrates the use of wireshark to inspect and analyze network packets.
The activity focused on examining packet structures, identifying network protocols, analyzing packet headers, applying display filters, and investigating DNS, ICMP, and HTTP, traffic.

## Skills Demonstrated

-  Packet Analysis
-  Wireshark
-  Network Monitoring
-  Traffic Inspection
-  Protocol Analysis
-  DNS Analysis
-  HTTP Analysis
-  Network Investigation

## Technologies Used

-  Wireshark
-  IPv4
-  Ethernet II
-  TCP
-  UDP
-  DNS
-  ICMP
-  HTTP

## Outcome

This project demonstrates how packet captures can be analyzed to understand network communications, identify endpoints, investigate DNS resolutions, and support security investigations.
