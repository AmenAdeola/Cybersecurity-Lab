# NIST CSF Incident Response

## Objective

Apply the NIST Cybersecurity Framework (CSF) to analyze and respond to a network security incident involving an ICMP flood attack.

## Skills Demonstrated

-  NIST Cybersecurity Framework (CSF)
-  Incident Response
-  ICMP Analysis
-  Network Security Monitoring
-  Firewall Hardening
-  IDS/IPS Implementation
-  Risk Mitigation
-  Security Docuementation


## NIST functions Applied

-  Identify
-  Protect
-  Detect
-  Respond
-  Recover

## Key Findings

A large volume of ICMP packets entered the organization's network through an improperly configured firewall, causing internal network services to become unavailable for approximately two hours.

The coursera exemplar classifies the incident as an ICMP Flood DDoS attack. However, the scenario itself does not explicitly provide any evidence  of multiple attacks sources. Based on the avilable information, an ICMP Flood attack can be confirmed.

## Security Improvements

-  ICMP rate limiting
-  Source IP verification
-  IDS?IPS deployment
-  Enhanced network monitoring
-  Firewall hardening
