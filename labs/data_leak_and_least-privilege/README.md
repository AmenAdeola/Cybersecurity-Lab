# Data Leak and Least Privilege

## Overview 

This project analyzes a data leak incident involving the accidental disclosure of internal company information to an external business partner.

Using the NIST SP 800-53 AC-6 9Least Privilege) control, the incident was evaluated to identify weaknesses in access management and recommend improvements to data handling pratices.

-  Principle of Least Privilege
-  Access Management
-  Information Privacy
-  Security Controls
-  Data Handling Pratices

## Outcome 

This project demonstrates how poor access management can contribute to data leaks and how least privilege controls can reduce the likelihood of future incidents.
