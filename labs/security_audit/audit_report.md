# Botium toys s=Security Audit Project

## Audit Scope

The audit covers  Botium Toys' physical operations, online business system, customer information, employee access management, and payment processing environment.

## Audit Goals

-  Protect organizational assets
-  Identify existing risks
-  Evaluate current security controls
-  Improve regulatory compliance
-  Reduce business impact of security incidents

  ## Critical Assets

  -  Customer information
  -  Employee workstations
  -  Payment processing systems
  -  Inventory systems
  -  Online store platform


 ## Existing Controls

 Implemented Controls:

 -  Firewall
 -  Antivirus software
 -  CCTV surveillance
 -  Locks
 -  fire detection and prevention systems
 -  Monitoring of legacy systems


Missing Controls:

-  Least privilege
-  Separation of duties
-  Encryption
-  Intrusion Detection System (IDS)
-  Centralized password management
-  Backup procedures
-  Disaster recovery plan


## Compliance

### PCI DSS

Current Status:

-  Authorized user controls: No
-  Secure cardholder environment: No
-  Data encryption procedures : No
-  Password management policies : NO

### GDPR

Current Status:

-  Customer data privacy : No
-  72-hour breach notification plan: Yes
-  Data classification and inventory : No
-  Privacy policies and procedures : Yes


  ## Conclusion

  Botium Toys should prioritize access management, encryption, backup processes, and incident detection capabilities to reduce risks and improve compliance with PCI DSS and  GDPR requirements.
