# Botium Toys Security Audit

# Overview
An internal security audit of a fictional organization used to evaluate assets, controls, compliance considerations, risks, and recommended improvements.

## Objective

Conduct an internal security audit for Botium Toys using the NIST Cybersecurity framework (CSF)

The purpose of this audit is to identify security risks, evaluate existing controls assess compliance requirements, and provide recommendations to improve the organization's security posture.


##Skills demonstrated

-  Risk identification & Assessment
-  Security Audit
-  Controls assessment
-  Internal Controls Evaluation
-  PCI and DSS compliance Review
-  Security Recommendtions
-  Documentation and Reporting

 
 ## Tools and Technologies
 
 - NIST Cybersecurity Framework
 - CIS Controls concepts
 
 
## Key Findings

The audit identified several missing security controls that increase organizational risk, including:

-  No last privilege access controls
-  no separation of duties
-  no encryption for sensitive data
-  no intrusion detection system (IDS)
-  no centralized password management
-  no backup strategy
-  no disaster recovery plan

##Compliance Standards Reviewed

-  PCI DSS
-  GDPR

## Recommendations

-  Implement least privilege access controls
-  Encrypt sensitive information
-  Deploy an instrusion detection system
-  Implement automated backups
-  Create a disaster recovery plan
-  Strengthen password management practices

 ## Outcome
 
 The audit identifies control gaps and provides prioritized recommendations to strengthen the organization’s security posture.
