# Security Audit

## Objective

Assess the organization’s current security posture and recommend controls that reduce risk.

## Scope and Goals

The audit reviews organizational assets, administrative and technical controls, access management, data protection, business continuity, and security monitoring. The goal is to identify gaps that could affect confidentiality, integrity, or availability.

## Current Assets

- Employee workstations and mobile devices
- Network equipment
- Business applications
- Customer and employee information
- Financial and operational records
- Physical office resources


## Control Categories

| Category | Examples |
|----------|----------|
| Administrative | Policies, procedures, training, asset ownership |
| Technical | MFA, encryption, firewalls, IDS/IPS, logging |
| Physical | Locks, cameras, badges, environmental controls |

## Key Findings

- Some security controls are present but are not consistently documented.
- Access should follow least privilege and role-based access requirements.
- Sensitive data should be protected in storage and transit.
- Logging, monitoring, backups, and recovery procedures should be regularly tested.

## Recommendations

1. Formalize access-control and acceptable-use policies.
2.  Implement MFA for sensitive systems.
3.  Encrypt sensitive data at rest and in transit.
4.  Maintain tested backups and disaster-recovery procedures.
5.  Centralize logging and monitor important security events.
6.  Conduct recurring vulnerability assessments and security awareness training.
