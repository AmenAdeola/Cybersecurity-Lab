# Debug Python Code  

## Objective  

Identify and correct syntax, runtime, and logic errors.  

## Core Code and Explanation 

Examples of corrections: 

```python 
for i in range(10):
  print("Connection cannot be established")
```
Add missing commas between list items, closing parentheses in function calls, valid variable names, `==` for comparison, valid list indices, colons after `with` or `if`, and call `.split()` on the string object.  

Document whether each issue is a `SyntaxError`, `NameError`, `IndexError`, `AttributeError`, indentation problem, or logic error. 

## Key Takeaways 

The lab combines foundational Python syntax with a security scenario. Keep the code, observed output, answers to reflection questions, and a short security relevance section in the GitHub file.
