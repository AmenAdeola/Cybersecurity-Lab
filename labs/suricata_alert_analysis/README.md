# Suricata Alert Analysis

## Overview

This project demonstrates how suricata can be used as a network intrusion detection system (IDS) to inspect network traffic, trigger alerts, and generate logs.
The  activity explored Suricata rule syntax, alert generation, packet analysis, and log investigation using both 'fast.log' and 'eve.json'.

## Skills demonstrated

-  Intrusion Detection Systems (IDS)
-  Suricata
-  Signature-Based Detection
-  Alert Analysis
-  Network Traffic Monitoring
-  Event Correlation
-  Linux Log Investigation

## Tools Used
-  Suricata
-  jq
-  Linux Terminal

## Files Analyzed
-  sample.pcap
-  custom.rules
-  fast.log
-  eve.json

## Outcome
This project demonstrate how suricata applies custom detection rules to packet capture, generates alerts, and records detailed security events in JSON format for investigation and analysis.
