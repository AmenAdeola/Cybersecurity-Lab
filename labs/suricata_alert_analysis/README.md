# Suricata Alert Analysis

# Explore Signatures and Logs with Suricata

This lab applies a custom Suricata signature to a packet capture and investigates the generated alerts and JSON events

## Overview

This project demonstrates how suricata can be used as a network intrusion detection system (IDS) to inspect network traffic, trigger alerts, and generate logs.
The  activity explored Suricata rule syntax, alert generation, packet analysis, and log investigation using both 'fast.log' and 'eve.json'.

## Outcome
This project demonstrate how suricata applies custom detection rules to packet capture, generates alerts, and records detailed security events in JSON format for investigation and analysis. In summary, the activity demonstrates how an IDS turns network traffic into structured alert evidence.
