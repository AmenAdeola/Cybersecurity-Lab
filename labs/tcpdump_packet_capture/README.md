# Tcpdump Packet Capture and Analysis

## Overview

This project demonstrated the use of tcpdump to capture, inspect, filter, and save network traffic from a linux system.

The activity focuses on identifying network interfaces, capturing network packets, saving packet capture (PCAP) files, inspecting packet headers, and analyzing network communications using command-line tools.

## Skills Demonstrated
-  Packet Capture
-  Packet Filtering
-  Network Traffic Analysis
-  Linux Networking
-  Tcpdump
-  Packet Inspection
-  Incident Investigation
-  Network Monitoring

## Tools Used
-  Linux Terminal
-  tcpdump
-  curl
-  ifconfig

## Outcome

This project demonstrated how a security analyst can capture, inspect, and filter network traffic to support investigations, threat hunting, and incident response activities.
