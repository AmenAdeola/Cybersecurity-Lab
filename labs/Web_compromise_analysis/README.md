# Web Compromise Analysos

## Objective

Analyze a web compromise incident involving a brute force attack, website defacement, malicious JavaScript injection, malware distribution, and user redirection.

## skills Demonstrated

-  Brute force Attack Analysis
-  DNS Analysis
-  HTTP analysis
-  Malware Investigation
-  Incident documentation
-  Security Hardening Recommendation

  ## Protocols Identified

  -  DNS
  -  HTTP

## Recommendations

-  Implement MFA
-  Enforce strong password policies
-  Remove default credentials
-  Monitor administrative accounts
-  Regularly review website source code
