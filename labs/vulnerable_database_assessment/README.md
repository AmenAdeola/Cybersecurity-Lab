# Vulnerable Database Assessment

## Overview

This project analyzes a publicly accessible database server for small e-commerce business.
A vulnerability assessment was performed using concepts from NIST SP 800-30 Rev .1 to identify potential threat sources, threat events, risks and remediation strategies.

## Skills Demonstrated
-  Vulnerability Assessment
-  Risk Assessment
-  Threat Modeling
-  Risk Analysis
-  Security Controls
-  Remediation Planning
-  NIST SP 800-30
-  Database Security

## Key Concepts
-  Threat Sources
-  Threat Events
-  Likelihood
-  Severity
-  Risk Scoring
-  Remediation Strategies

## Outcome

This assessment identified critical risks associated with exposing a database server to the public internet controls to reduce the organization's attack surface.
