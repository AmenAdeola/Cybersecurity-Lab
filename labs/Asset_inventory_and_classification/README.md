# Asset Inventory and Classification

## Overview

This project demonstrates the identification, classification, and documentation of organizational assets.

Assets were evaluated according to their ownership, network access requirements, location, business purpose, and sensitivity level.

## Skills Demonstrated

-  Asset Inventory Management
-  Asset Classification
-  Risk Identification
-  Data Sensitivity Assessment
-  Security Documentation

## Assets Reviewed

-  Network Router
-  Desktop
-  Guest Smarphone
-  External Hard Drive
-  Steaming Media Player
-  Portable Game Console


## Sensitivity Levelsn

-  Restricted
-  Confidential
-  Internal-only
-  Public

## Outcome

This activity demonstrates how asset inventories support cybersecurity risk management by helping organizations identify critical assets and determine appropriate protection requirements
